## Unix and Linux History
```
1969 Unix was developed
- Created by Bell Labs
- Originally developed in an assembly language
- Rewritten in C in the early 1970s
- Touted for being portable
- Popularized the hierarchical file system
```

```
1978 UC Berkeley Developed BSD
- Berkely Software Distribution
- A "unix-like" system
- a derivative of UNIX
```

```
1983 GNU Operating System Development Began
- Started by Richard Stallman
- GNU stands for GNU's Not Unix
- It is unix like
- Didn't have a production stable kernel until early 2000s
```

```
1991 Linux Kernel Development Begins
- Created by Linus Torvalds
- Originally referred to as Freax (free + x)
- He didn't want it to be called linux because he thought it was too egotistical
- Others disagreed and thought Freax sounded terrible
```

```
1992 GNU OS and Linux Kernel Combinded
- Keep in mind, Linix is just the kernal
- The OS is called GNU/Linux
```

```
1992 BSD folks are sued by AT&T
- Slows BSD development
- Opens the door for GNU/Linux to rise
```

```
1993 Debian was born
- Debian Distros include
    - Raspberry Pi OS
    - Ubuntu
    - Steam OS (originally)
    - and more
```

```
1994 Redhat Distro born
- Tends to be used for enterprise applications
    - Fedora
    - CentOS
    - and more
```
