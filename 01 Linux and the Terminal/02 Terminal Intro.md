### Terminal Intro
Def: The shell is a program that is interpreting the commands you type into the application called the terminal

Def: The terminal is the application that lets you access and interact with the shell

While not technically the same thing, we often use these terms interchangeably

```
Common Terminals:
- Terminal (or Terminal Emulator) on Linux Distros
- Terminal on Windows
- Terminal on MacOS

Common Shells:
- Bourne Again Shell (bash)
- z shell (zsh)
- powershell (pwsh)
- gitbash
- fish - friendly interactive shell
- python shell
```
